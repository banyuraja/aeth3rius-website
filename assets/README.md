# Aeth3rius Assets Guide

Drop your real brand logo and product photography into these folders, then point to them inside `js/catalog-data.js`.

## Recommended Files & Aspect Ratios

| Folder | Suggested Filename | Recommended Ratio / Size |
| :--- | :--- | :--- |
| `assets/brand/` | `logo.svg` or `logo.png` | Transparent horizontal mark (~48px height) |
| `assets/hero/` | `hero.webp` or `hero.jpg` | `1:1` square editorial shot (e.g. `1200×1200px`, < 250 KB) |
| `assets/products/` | `vertex-grips.webp` (or `.jpg`) | `1:1` square studio shot (e.g. `1000×1000px`, < 180 KB) |
| `assets/products/` | `apex-grips.webp` (or `.jpg`) | `1:1` square studio shot |
| `assets/products/` | `short-vertex-grips.webp` (or `.jpg`) | `1:1` square studio shot |
| `assets/products/` | `short-apex-grips.webp` (or `.jpg`) | `1:1` square studio shot |
| `assets/products/` | `devil-grips.webp` (or `.jpg`) | `1:1` square studio shot |

> **Tip for Stealth Dark Mode Photography:** Shoot on a matte dark charcoal or pitch-black backdrop with crisp rim lighting so product cards blend seamlessly into the `#000000` dark theme.
